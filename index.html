Materi 1

Bentuk umum fungsi kuadrat

Fungsi kuadrat adalah fungsi yang pangkat tertinggi variabelnya dua. Grafiknya selalu berbentuk parabola.

f(x) = ax² + bx + c  dengan a ≠ 0
aKoefisien x². Menentukan arah buka dan lebar parabola.
bKoefisien x. Bersama a, menentukan posisi puncak.
cKonstanta. Titik potong grafik dengan sumbu y, yaitu (0, c).
Mengapa a tidak boleh 0? Jika a = 0, suku x² hilang dan f(x) = bx + c menjadi garis lurus, bukan parabola.
Contoh 1Tentukan a, b, c dari f(x) = −x² + 5x − 7, lalu hitung f(2).
  1. Cocokkan dengan ax² + bx + c: a = −1, b = 5, c = −7.
  2. f(2) = −(2)² + 5(2) − 7 = −4 + 10 − 7 = −1.
a = −1, b = 5, c = −7, f(2) = −1
Contoh 2Pada f(x) = 3x² − 4, berapa nilai b?
  1. Tulis lengkap: f(x) = 3x² + 0x − 4.
  2. Tidak ada suku x, sehingga koefisiennya 0.
b = 0 (a = 3, c = −4)
Materi 2

Grafik parabola dan unsur-unsurnya

Parabola punya sumbu simetri yang membagi grafik menjadi dua sisi yang sama. Titik puncak berada tepat di sumbu itu.

Contoh: f(x) = x² − 4x + 3

  • Arah buka. a > 0 terbuka ke atas, puncak adalah nilai minimum. a < 0 terbuka ke bawah, puncak adalah nilai maksimum.
  • Sumbu simetri. x = −b / 2a
  • Titik puncak. (−b / 2a , f(−b / 2a)). Nilai y puncak juga bisa dihitung dengan c − b² / 4a.
  • Potong sumbu y. (0, c)
  • Potong sumbu x. Titik dengan f(x) = 0, dibahas di Materi 3.
Contoh 1Untuk f(x) = x² − 4x + 3, tentukan arah buka, titik puncak, dan titik potong sumbu y.
  1. a = 1 > 0, jadi parabola terbuka ke atas.
  2. x puncak = −(−4) / (2 · 1) = 2.
  3. y puncak = f(2) = 4 − 8 + 3 = −1.
  4. Potong sumbu y di (0, c) = (0, 3).
Terbuka ke atas, puncak (2, −1) minimum, potong sumbu y (0, 3)
Contoh 2Tentukan nilai maksimum f(x) = −2x² + 8x − 5.
  1. a = −2 < 0, jadi puncak adalah nilai maksimum.
  2. x puncak = −8 / (2 · (−2)) = 2.
  3. f(2) = −2(4) + 8(2) − 5 = −8 + 16 − 5 = 3.
Nilai maksimum = 3, tercapai saat x = 2
Materi 3

Akar-akar fungsi kuadrat

Akar adalah nilai x yang membuat f(x) = 0. Secara grafik, akar adalah titik tempat parabola memotong sumbu x. Ada dua cara utama mencarinya:

  • Pemfaktoran. Cari dua bilangan yang jumlahnya b dan hasil kalinya c (untuk a = 1).
  • Rumus kuadrat. Selalu bisa dipakai.
x = (−b ± √D) / 2a  dengan  D = b² − 4ac
DiskriminanBanyak akarPosisi grafik
D > 0Dua akar berbedaMemotong sumbu x di dua titik
D = 0Satu akar kembarMenyentuh sumbu x di puncak
D < 0Tidak ada akar realTidak menyentuh sumbu x
Contoh 1Selesaikan x² − 5x + 6 = 0 dengan pemfaktoran.
  1. Cari dua bilangan berjumlah −5 dan berhasil kali 6: −2 dan −3.
  2. Faktorkan: (x − 2)(x − 3) = 0.
  3. Setiap faktor bernilai nol: x = 2 atau x = 3.
x = 2 atau x = 3
Contoh 2Selesaikan 2x² + 3x − 2 = 0 dengan rumus kuadrat.
  1. a = 2, b = 3, c = −2.
  2. D = 3² − 4(2)(−2) = 9 + 16 = 25, sehingga √D = 5.
  3. x = (−3 ± 5) / 4, jadi x = 2/4 = 1/2 atau x = −8/4 = −2.
x = 1/2 atau x = −2
Contoh 3Berapa banyak titik potong f(x) = x² − 2x + 3 dengan sumbu x?
  1. D = (−2)² − 4(1)(3) = 4 − 12 = −8.
  2. D negatif, jadi tidak ada akar real.
  3. Cocok dengan grafik: a > 0 dan puncak (1, 2) berada di atas sumbu x.
Tidak ada titik potong dengan sumbu x
Materi 4

Menyusun fungsi kuadrat

Kadang yang diketahui adalah grafiknya, dan kamu diminta mencari rumusnya. Pilih bentuk yang sesuai dengan informasi yang ada.

f(x) = ax² + bx + cDipakai jika diketahui tiga titik pada grafik.
f(x) = a(x − p)(x − q)Dipakai jika akarnya p dan q diketahui.
f(x) = a(x − h)² + kDipakai jika puncaknya (h, k) diketahui.
Contoh 1Grafik memotong sumbu x di x = −1 dan x = 3, serta melalui (0, −6). Tentukan fungsinya.
  1. Bentuk akar: f(x) = a(x + 1)(x − 3).
  2. Substitusi (0, −6): a(1)(−3) = −6, sehingga a = 2.
  3. f(x) = 2(x² − 2x − 3) = 2x² − 4x − 6.
f(x) = 2x² − 4x − 6
Contoh 2Puncak grafik di (2, −1) dan melalui (0, 3). Tentukan fungsinya.
  1. Bentuk puncak: f(x) = a(x − 2)² − 1.
  2. Substitusi (0, 3): a(0 − 2)² − 1 = 3, jadi 4a = 4 dan a = 1.
  3. f(x) = (x − 2)² − 1 = x² − 4x + 3.
f(x) = x² − 4x + 3
